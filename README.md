A deep-sea theme in dark and light: a mint glow on deep navy or soft paper.

## Themes

Biolume comes in two themes:

- **Biolume**: deep navy with a mint glow.
- **Biolume Light**: soft paper with deep green accents.

![Biolume Light with a TypeScript file open](assets/screenshots/light.png)

## Install

Biolume is published on both registries:

- [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kostad02.biolume), for VS Code.
- [Open VSX](https://open-vsx.org/extension/kostad02/biolume), for VSCodium and other editors that use it.

From inside your editor:

1. Open the **Extensions** view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS), search for **Biolume** and select **Install**.
2. Run **Preferences: Color Theme** (`Ctrl+K Ctrl+T`, or `Cmd+K Cmd+T` on macOS) and pick **Biolume** or **Biolume Light**.

Or from the command line:

```sh
# VS Code
code --install-extension kostad02.biolume

# VSCodium
codium --install-extension kostad02.biolume
```
